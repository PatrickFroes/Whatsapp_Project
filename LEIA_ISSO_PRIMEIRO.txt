COMO VER MELHOR OS CODE BLOCKS NO VS CODE
==========================================

OPÇÃO 1 - AUMENTAR ZOOM (RECOMENDADO)
====================================

Pressione: Ctrl + (plus/+)
Pressione: Ctrl + (plus/+) mais uma vez
Pressione: Ctrl + (plus/+) uma terceira vez

Isso aumenta o zoom para 120% ou 150%

Para voltar ao normal: Ctrl + 0 (zero)


OPÇÃO 2 - ALTERAR CONFIGURAÇÕES DO VS CODE
===========================================

1. Abra Settings: Ctrl + ,
2. Procure por: "editor.fontSize"
3. Aumente de 14 para 16 ou 18
4. Procure por: "editor.lineHeight"
5. Coloque: 1.8 ou 2
6. Procure por: "editor.wordWrap"
7. Selecione: "on"
8. Feche Settings

Isso deixa o texto maior e mais legível


OPÇÃO 3 - USAR FONTE MONOSPACE MELHOR
====================================

1. Abra Settings: Ctrl + ,
2. Procure por: "editor.fontFamily"
3. Troque para uma dessas fontes (em ordem de preferência):
   - "Consolas"
   - "Monaco"
   - "Courier New"
   - "JetBrains Mono"

4. Recarregue o VS Code


OPÇÃO 4 - COPIAR TEXTO DO CODE BLOCK
===================================

Se o text block for pequeno demais:

1. Clique no code block
2. Pressione Ctrl + A (selecionar tudo)
3. Pressione Ctrl + C (copiar)
4. Abra o terminal
5. Pressione Ctrl + V (colar)

O texto vai aparecer por completo no terminal


SE AINDA NÃO FUNCIONAR:
====================

1. Feche VS Code completamente
2. Abra novamente
3. Se o problema persistir, qual é exatamente o problema?
   - O texto está muito pequeno?
   - O background está escondendo o texto?
   - O bloco está truncado (cortado)?
   - Precisa fazer scroll?

Descreva melhor e eu acho a solução!
