SOLUÇÃO 2 - COMANDO SSH COM KEEPALIVE
======================================

Esta é a forma MAIS RÁPIDA - sem alterar o servidor.

EXECUTE ESTE COMANDO TODA VEZ QUE CONECTAR:

ssh -o ServerAliveInterval=300 -o ServerAliveCountMax=10 amberfy-test@172.233.26.198

Explicação:
- ServerAliveInterval=300: Envia ping a cada 300 segundos (5 minutos)
- ServerAliveCountMax=10: Permite 10 pings sem resposta
- Total: 300 * 10 = 3000 segundos = 50 minutos sem desconectar

OUTRAS OPÇÕES DE TEMPO:

1 HORA (3600 segundos):
ssh -o ServerAliveInterval=300 -o ServerAliveCountMax=12 amberfy-test@172.233.26.198

4 HORAS:
ssh -o ServerAliveInterval=300 -o ServerAliveCountMax=48 amberfy-test@172.233.26.198

8 HORAS:
ssh -o ServerAliveInterval=300 -o ServerAliveCountMax=96 amberfy-test@172.233.26.198

NUNCA DESCONECTAR (até fechar terminal):
ssh -o ServerAliveInterval=60 -o ServerAliveCountMax=1000 amberfy-test@172.233.26.198


CRIAR ALIAS (OPCIONAL - para não digitar toda vez):
====================================================

No seu PC, abra PowerShell e execute:

$profile

Isso vai mostrar um caminho tipo:
C:\Users\SeuUsuario\Documents\PowerShell\profile.ps1

Se não existir, crie. Depois adicione esta linha:

Set-Alias ssh-broker 'ssh -o ServerAliveInterval=300 -o ServerAliveCountMax=96 amberfy-test@172.233.26.198'

Salve.

Depois, para conectar, você só digita:
ssh-broker
