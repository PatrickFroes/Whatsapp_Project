COMANDO PARA VER USUÁRIOS E SENHAS DE UM TENANT
================================================

OPÇÃO 1 - VIA TERMINAL (listar todos os usuários):

docker compose exec -T broker_app node -e "
const { PrismaClient } = require('@prisma/client');
const p = new PrismaClient();
p.user.findMany({include:{tenant:{select:{name:true}}}}).then(users=>{
  users.forEach(u=>console.log('Email:',u.email,'| Tenant:',u.tenant.name,'| Role:',u.role));
  p.\$disconnect();
});
"


OPÇÃO 2 - VER USUÁRIOS DE UM TENANT ESPECÍFICO:

docker compose exec -T broker_app node -e "
const { PrismaClient } = require('@prisma/client');
const p = new PrismaClient();
const tenantName = 'Empresa'; // Mude para seu tenant
p.user.findMany({
  where:{tenant:{name:{contains:tenantName}}},
  include:{tenant:{select:{name:true,slug:true}}}
}).then(users=>{
  console.log('=== USUÁRIOS DO TENANT ===\n');
  users.forEach(u=>console.log('Email:',u.email,'Role:',u.role));
  p.\$disconnect();
});
"
