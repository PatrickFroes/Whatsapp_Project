COMANDO PARA CRIAR NOVO SUPER ADMIN
====================================

No servidor, execute este comando:

docker compose exec -T broker_app node /app/scripts/create_super_admin.js seu_email@example.com sua_senha_aqui

EXEMPLO:
docker compose exec -T broker_app node /app/scripts/create_super_admin.js admin@broker.com.br MinhaSenh@123


PASSO A PASSO:

1. No servidor, execute:
cd ~/Broker/Broker

2. Depois execute o comando acima com seu email e senha


SUCESSO:
Você verá uma mensagem assim:
✅ Super Admin Created Successfully!
----------------------------------
User:  Super Administrator
Email: admin@broker.com.br
Role:  SUPER_ADMIN
Tenant: Platform Administration
----------------------------------
You can now access /super.html

ACESSO:
URL: https://broker.amber.com.br/super.html
Email: seu_email_aqui
Senha: sua_senha_aqui
