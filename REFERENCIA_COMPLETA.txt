COMANDOS NO SERVIDOR
════════════════════

Copiar arquivo para container Docker:
docker compose cp arquivo.js broker_app:/app/

Reiniciar container:
docker compose restart broker_app

Ver logs:
docker compose logs -f broker_app

Procurar por erro específico:
docker compose logs broker_app | grep -i "erro\|error\|failed"

Listar usuários:
docker compose exec -T broker_app node -e "const { PrismaClient } = require('@prisma/client'); const p = new PrismaClient(); p.user.findMany({include:{tenant:{select:{name:true}}}}).then(users=>{ users.forEach(u=>console.log('Email:',u.email,'| Tenant:',u.tenant.name,'| Role:',u.role)); p.$disconnect(); });"

Resetar senha de usuário:
docker compose exec -T broker_app node /app/reset-user-password.js email@exemplo.com NovaSenha123

Criar novo Super Admin:
docker compose exec -T broker_app node /app/scripts/create_super_admin.js newemail@example.com NovaSenh@123

FIREWALL - LIBERAR IPs META
═══════════════════════════

Se usar firewalld (CentOS/RHEL):
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="31.13.64.0/18" port protocol="tcp" port="443" accept'
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="31.13.128.0/17" port protocol="tcp" port="443" accept'
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="31.13.192.0/18" port protocol="tcp" port="443" accept'
sudo firewall-cmd --reload

Se usar ufw (Ubuntu/Debian):
sudo ufw allow from 31.13.64.0/18 to any port 443
sudo ufw allow from 31.13.128.0/17 to any port 443
sudo ufw allow from 31.13.192.0/18 to any port 443
sudo ufw reload
