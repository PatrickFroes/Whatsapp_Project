Phone Number ID
O que é?

É o identificador único do seu número de telefone no WhatsApp Business. Este ID é necessário para enviar mensagens através da API.

Como obter?
  1. Acesse https://developers.facebook.com/apps/
  2. Selecione seu app WhatsApp
  3. Vá em API Setup ou WhatsApp → Getting Started
  4. Você verá o campo "Phone Number ID" no painel
  5. Copie o valor (é um número de 15 dígitos)
Exemplo
958814803984993
Importante: Cada número de telefone tem seu próprio ID. Certifique-se de usar o ID do número que está configurado em sua conta Meta.
Verify Token
O que é?

É uma senha/token que você cria e usa para validar requisições do webhook Meta. Serve como camada adicional de segurança.

Como criar?
  1. Crie uma senha forte (mínimo 8 caracteres)
  2. Exemplo: minha_senha_segura_webhook
  3. Configure este mesmo token em:
    • Seu servidor (aqui nesta configuração)
    • Meta Dashboard → App → Configurações → Webhooks → Verify Token
  4. Meta usará este token para validar chamadas ao seu webhook
Dicas de Segurança
  • ✅ Use uma senha forte e aleatória
  • ✅ Mude periodicamente
  • ❌ Não use senhas simples ou padrão
  • ❌ Não compartilhe publicamente
Nota: Este token é diferente do Access Token. É usado apenas para validar webhooks.
WhatsApp Access Token
O que é?

É o token de autenticação para fazer requisições à API do WhatsApp. Permite que seu servidor envie mensagens, gerencias webhooks, etc.

Tipos de Token
  • Token Temporário: Válido por ~60 dias (bom para testes)
  • Token Permanente (RECOMENDADO): Válido indefinidamente
Como obter Token Permanente?
  1. Acesse https://developers.facebook.com/apps/
  2. Selecione seu app
  3. Vá em Settings → Basic
  4. Encontre o App ID e App Secret
  5. Use uma ferramenta como cURL ou Postman para gerar o token: 
    POST https://graph.instagram.com/oauth/access_token
client_id=SEU_APP_ID
client_secret=SEU_APP_SECRET
grant_type=client_credentials
Segurança
Crítico:
  • Nunca compartilhe este token
  • Não exponha em código público (git, etc)
  • Revogue e gere novo se comprometido
Meta App Secret
O que é?

É a chave secreta de sua aplicação Meta. Usada para validar assinatura HMAC dos webhooks, garantindo que as requisições vêm realmente de Meta.

Por que é importante?
  • ✅ Valida autenticidade dos webhooks
  • ✅ Protege contra requisições falsificadas
  • ✅ Previne ataques MITM (Man-in-the-Middle)
  • ✅ É obrigatório em produção
Como obter?
  1. Acesse https://developers.facebook.com/apps/
  2. Selecione seu app WhatsApp
  3. Vá em Settings → Basic
  4. Procure por "App Secret"
  5. Clique em [Show] para revelar o valor
  6. Copie o valor completo
Como Funciona?
  1. Meta calcula: HMAC-SHA256(payload, APP_SECRET)
  2. Meta envia resultado no header: X-Hub-Signature-256
  3. Seu servidor recalcula o HMAC
  4. Se coinciderem → Webhook é legítimo ✅
  5. Se não → Webhook é rejeitado ❌
Crítico:
  • Nunca compartilhe este valor
  • Revogue e gere novo se comprometido
  • Não exponha em logs ou código
